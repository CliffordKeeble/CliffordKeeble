# Clifford Keeble

AI .NET engineer. Thirty years building systems for UK financial services, energy and government. PhD in computer science, University of Southampton.

## Demos

- **[motor-quote-demo](https://github.com/CliffordKeeble/motor-quote-demo)**: a car insurance quote journey, React and Angular front ends on a .NET 10 Azure Functions API. The insurer is fictional and the prices illustrative. Live: [React](https://wonderful-mushroom-05443000f.6.azurestaticapps.net/) · [Angular](https://ashy-dune-08048570f.1.azurestaticapps.net/)
- **[elliptic-workbench](https://github.com/CliffordKeeble/elliptic-workbench)**: the rank-0 Birch and Swinnerton-Dyer formula over ℚ in .NET, with a high-precision arithmetic core. [Live](https://elliptic-workbench.clifford-keeble.workers.dev/)
- **[aspire-ai-routing-demo](https://github.com/CliffordKeeble/aspire-ai-routing-demo)**: .NET Aspire message routing over Azure Service Bus, with a swappable AI classifier (keyword, local model or OpenAI) and OpenTelemetry tracing of the whole path.
- **[BestStoriesApi](https://github.com/CliffordKeeble/BestStoriesApi)**: an ASP.NET Core API returning the best Hacker News stories by score, without overloading the Hacker News API.
